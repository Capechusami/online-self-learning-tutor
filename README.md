# Online Self-Learning Tutor (EduSmart K-12)

Monorepo for the Smart Online Learning System (SOLS).

## Structure

```
online-self-learning-tutor/
├─ apps/
│  ├─ web/    # React + Vite + TS + Tailwind frontend
│  └─ api/    # Node.js (Express + TS) backend
```

## Quick start

```bash
# install everything (npm workspaces)
npm install

# run the web app
npm run dev

# run the api (separate terminal)
npm run dev:api
```

Web app: http://localhost:5173  
API: http://localhost:4000
